# Native photo workspace
- `main.py` is the Windows desktop entrypoint; `studio/` owns Qt widgets, file browsing, workers and template editing. Keep the entrypoint and package names; do not reintroduce the previous desktop_ui/desktop.py names.
- Localization lives in studio/i18n.py: tr/register_translations/bind/translator.language_changed. All fixed UI strings must have Chinese+English, including standard Qt buttons/calendars; never translate file names, camera brands or user edits. Language preference is separate ignored config/ui.json; switching locale must not invalidate previews or discard queues/drafts.
- TemplateWizard starts from presets/current/valid blank frame and embeds the same free field composer as the main editor. Fields are independent; do not regress to fixed checkbox-to-region assignment or a locked exposure group. For composition schema, helpers, exact source preservation and handoff: `mem:footer`.
- Photo information editing, migration and copy protection: `mem:metadata`.
- PySide6 UI runs offline. User now prefers charcoal/gray-black layers, restrained gray-blue selection and small rounded buttons/inputs. Main toolbar follows add photos -> edit photo info -> compose watermark -> export; export reflects checked count, saving settings is distinct from saving templates. Keep the inset side-by-side color swatches. User prefers a compact professional dark photo workspace: native menus/toolbars, input/output file trees, central image canvas and parameter inspector, without decorative cards, slogans or step labels. Source browser UI remains under web_server.py/templates for existing users.
- `core/desktop_service.py` adapts existing processor pipelines for previews/full-resolution exports, template CRUD and workspace settings. `WatermarkSettings` snapshots isolate background jobs from edits.
- Default use_template_styles=True preserves template styling; EXIF session overrides still apply. Quick style edits explicitly opt into overrides. Center-logo rendering contains the whole logo inside footer padding and honors canonical center_logo_height plus legacy center_height. The main centered-brand preset now includes camera/lens/exposure/date columns; 仅标识居中 is the separate compact logo-only preset. fit_center_columns reserves the center slot and shrinks long side text to avoid overlaps. `template_source` holds an unsaved preview draft and is never persisted in personal JSON.
- Shared template/input/output/overwrite/quality/subsampling settings use config/config.ini as authority; stale desktop JSON must not override them. Explicit workspace save synchronizes INI and ignored config/desktop.json; template source writes remain explicit. Batch input_files and template drafts are session-only.
- Within input_dir, exports preserve relative directories and original stems; PNG remains PNG, JPEG/HEIC use JPEG. Existing output is skipped unless overwrite is enabled. Ad hoc photos outside the input root use *_watermarked names with unique numbering. Reject replacing source images or existing photos inside the input directory.
- ExifTool discovery supports exiftool.exe and exiftool(-k).exe; UTF-8 stdin argument streams support Chinese paths and prevent -k pauses. JSON -l provides canonical tags plus description-derived legacy keys; retain Unicode, remove NUL terminators. Cache keys include tool path/mtime/size so installing the tool refreshes prior fallback metadata.
- Raw-template mode preserves existing EXIF dimensions (including Orientation semantics), original Jinja environment, full batch files/tojson, RGB conversion and INI JPEG subsampling. Raw previews thumbnail the complete RGB render, cached separately; shortcut previews scale spatial parameters and use engine input_buffer for source reloading nodes. Never replace source images with prior pipeline outputs.
- Qt object mutations stay on the GUI thread. Background image tasks signal detached QImage copies, stale preview generations are ignored, cancellation occurs between photos, closing waits for tasks to finish.
- Conda can provide an incompatible icuuc.dll with versioned symbols. main.prepare_windows_runtime preloads Windows System32 ICU for the current process before importing Qt. build_support/sitecustomize.py applies the same fix to PyInstaller child processes; do not replace DLLs in the user environment.
- For pipeline implementation invariants: `mem:processor/core`. For local run/build validation: `mem:suggested_commands` and `mem:task_completion`.
