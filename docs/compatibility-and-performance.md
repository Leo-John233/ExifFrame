# 网页功能对照与性能验证

## 功能对照

对照范围为原网页 `templates/index.html`、`web_server.py` 与桌面窗口、后台任务及共用图像处理流程。下表描述桌面对应操作和有意保留的差异。

| 原网页功能 | 桌面对应操作与差异 |
| --- | --- |
| 输入、输出目录及刷新 | 文件区分别提供输入、输出标签和目录浏览，后台扫描并显示文件树、缩略图与尺寸；手动添加、拖入、移除和清空只改变队列，不删除文件 |
| 勾选文件、勾选文件夹、全选 | 输入文件树支持逐张勾选、文件夹三态选择、全选和取消选择；预览当前照片与导出勾选范围分开管理 |
| 质量、覆盖与配置保存 | 输出选项提供 JPEG 质量和覆盖开关，“保存设置”持久化目录与导出选项；桌面允许当前未保存设置用于本次导出，网页要求先保存配置 |
| 模板选择、编辑、新建及另存为 | 右侧模板选择、可视化组合、新建向导和高级源码编辑器提供对应操作；“保存模板”与“保存设置”分别持久化模板与工作区设置 |
| Jinja 照片和批次上下文 | 保留 `exif`、`filename`、`file_dir`、`file_path` 与所选 `files`；源码预览跟随勾选与会话照片信息更新，保留当前预览照片和草稿 |
| 输入和输出图片查看 | 输入照片可切换水印预览与原图；输出文件直接显示，不再叠加水印；导出后自动刷新输出树，也可打开输出目录 |
| 多图处理、进度和结果 | 导出所勾选照片，显示进度与成功、失败、跳过计数及错误详情；桌面额外支持取消，已启动照片结束后停止 |
| 目录结构、同名跳过或覆盖 | 输入目录内默认保留相对目录，也可选择扁平导出；PNG 保留 PNG，其他支持格式导出 JPEG。同名输出默认跳过，手动添加照片使用 `_watermarked` 后缀及必要的编号 |

照片信息编辑、会话覆盖、保存副本、中英文切换与新建模板示例图是桌面扩展。示例图只使用自己的文件和照片信息，不加入用户队列或使用用户临时 EXIF。共享 `config/config.ini` 仍保存色度采样参数；原网页和桌面均没有对应界面控件。

启用覆盖时，桌面同时保护已导入队列中勾选和未勾选的源照片。用于保护的完整队列与模板使用的勾选 `files` 分开，也不会持久化为设置。

## 处理策略

批量导出只在经核验的内置模板源码未修改、可用物理内存充足、照片可读取且输出目标互不冲突时最多同时处理两张照片。自定义模板、修改过的内置源码、多核检测失败、内存不足、照片尺寸无法读取或目标可能冲突时按原顺序逐张处理，因此可自由使用可能读取整批照片或放大画面的模板。当前内存门槛为 4 GiB 加上最大照片像素数乘以 224 字节，用于给系统和模板处理中间图像留出余量。

导出开始前，主窗口和模板编辑器停止启动新的预览任务，并等待已在处理的预览结束；导出结束或取消后恢复待更新预览。每批照片使用同一份模板源码快照。只提交有限数量的照片，取消后不再提交新的照片，已经开始的照片仍计入实际结果。

组合面板复用不含照片数据的预览模板与表达式缓存，每次仍独立传入照片信息、文件名和目录；质量、覆盖和输出目录等不影响水印画面的选项不再触发预览重算。

## 验证范围

本地回归覆盖网页配置与模板对应流程、目录树及选中状态、照片与批次上下文、EXIF 会话覆盖、示例隔离、不同草稿和照片的并发文字预览、同名与自动编号冲突、源照片和硬链接保护、进度和失败/跳过统计、取消、输出查看以及导出前后预览任务的等待和恢复。原片或模板引用的批次照片发生变化时，也检查预览和信息缓存是否失效。完整测试共 121 项，全部通过。真实照片验证仅使用原片读取，生成文件写入项目的临时缓存目录。

## 本机测量

在一台 Windows、Python 3.13、32 逻辑处理器的机器上，以四张约 1900 万至 2400 万像素的 JPEG 照片运行完整 ExifTool 流程。JPEG 质量为 60、色度采样为 2，可用物理内存约 10 GiB；每种情况分别启动进程，使用同一组照片与导出选项。数字为单次测量的整批导出时间，不包括界面导入和预览等待；峰值提交内存为主进程统计，不包括 ExifTool 子进程。

| 模板 | 单路用时 | 双路用时 | 单路峰值提交内存 | 双路峰值提交内存 |
| --- | ---: | ---: | ---: | ---: |
| 标准水印 | 5.524 秒 | 2.991 秒 | 572 MiB | 762 MiB |
| 背景模糊 | 17.637 秒 | 9.577 秒 | 1827 MiB | 2548 MiB |

两种模板的单路与双路结果逐张进行 SHA-256 比较，八对结果均一致；四张原片的校验值在测量前后保持不变。性能随照片、模板、磁盘和内存状况变化，双路只在前述条件满足时启用。

另以标准模板为输入，执行 100 轮文字示例计算，每轮包含完整文字区域及逐项字段计算；优化前为 1.790 秒，最终版本为 0.064 秒。此项只测量文字示例计算，不包含照片解码、水印图像渲染或窗口交互时间。
